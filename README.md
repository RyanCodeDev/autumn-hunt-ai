# Autumn Hunt AI

## Hacktoberfest 2026: Week 1 Challenge

A scavenger hunt type game that uses local AI (via Transformers.js) to detect autumn objects. The user snaps photos, which are analyzed locally on the user's phone, for autumn objects on their scavenger hunt list. As objects are detected, they are automatically crossed off the list.
